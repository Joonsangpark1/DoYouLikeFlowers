# SmolVLA + HIL-SERL 핸드오프 설계 (2026-11-13, 사용자 설계)

## 1. 전체 구조
- **SmolVLA:** 꽃을 보고 접근하는 것까지 담당하고, 핸드오프 구간 **H**에 도달하면 멈춘다.
- **HIL-SERL:** H에서 시작해서 정밀하게 파지한다.
- **핸드오프:** 제어권이 넘어가는 지점이다. 실험 변수는 **"꽃에서 얼마나 떨어진 곳에서 넘기느냐"**다.

## 2. 핵심 아이디어
HIL-SERL의 random start를 **VLA 마지막 자세의 분포**로 설계한다.
학습할 때와 배포할 때의 시작 상태가 같아지므로, 핸드오프 문제가 구조적으로 사라진다.

## 3. 데이터 수집
- 환경은 고정하고 **꽃 위치와 조명만** 바꾼다.
  - 꽃 위치는 홀더 격자로 정해서 p_f를 정확히 알아 둔다. 그러면 카메라 추정 오차가 분석에서 빠진다.
  - 조명은 VLA 강건성에만 영향을 주므로 바꿔도 된다.
- 시연은 **감으로** 모으고, 멈추는 지점을 규칙으로 강제하지 않는다. 시연자는 "접근해서 집기"만 하면 되고 끝을 따로 표시하지 않는다.
- 시연할 때 **전체 궤적의 FK 좌표**를 로깅한다. URDF와 TCP 오프셋을 쓴다.
- 모든 좌표는 꽃 기준 상대 좌표로 바꾼다: **d = p_ee − p_f** (yaw 오차 포함).

## 4. 핸드오프 구간 정하기 (데이터 수집 후, 데이터 기반)
1. 궤적에서 마무리 자세를 뽑는다. **그리퍼가 닫히기 전에 d_z가 X cm 안에 처음 들어온 지점**이다.
2. 그 분포를 분석하고 분류(클러스터링, GMM 등)한다.
   - **모드가 하나면** 그 분포로 H를 잡는다.
   - **모드가 여러 개면** 정해야 한다. 예를 들어 "왼쪽에서 접근"과 "위에서 접근"이 섞이면, VLA가 그 사이를 평균 내서 어중간한 곳으로 갈 수 있다(flow matching이라 덜하긴 하다). 모드 하나만 쓸지, H를 여러 개 둘지 결정한다.
3. 그 분포로 구간 H를 정한다(예: 95% 타원체 또는 퍼센타일 박스).
4. X를 4/6/10 cm 등으로 바꿔 가며 반복하면, **데이터를 다시 모으지 않고** 핸드오프 위치 실험이 된다.

## 5. 학습
- 핸드오프 **앞부분**은 SmolVLA 학습 데이터로 쓴다.
- 핸드오프 **뒷부분**은 HIL-SERL 초기 demo buffer로 쓴다.
- HIL-SERL 리셋은 H 분포에서 샘플링하되 조금 넓혀서 쓴다(노이즈나 uniform 샘플을 일부 섞음).

## 6. 실행 시 제약
- **전환 조건:** FK로 계산한 d가 H 안에 있고 k 스텝 동안 정지하면, 남은 chunk를 버리고 hold한 뒤 HIL-SERL로 넘긴다.
- **행동 제약:** HIL-SERL의 EE 목표를 꽃 기준 작업 공간 **W**로 clip한다(W ⊃ H).
- **종료:**
  - reward classifier가 성공으로 판정하면 끝낸다.
  - 시간 초과나 W 이탈이면 팔을 들어 올리고 SmolVLA로 돌아간다.

## 7. 분석 (논문 결과)
- 튜닝 후 VLA의 종료 분포를 측정해서 시연 분포와 비교한다: bias, 분산, H 커버리지.
- 튜닝 버전별 변화와 꽃 종류별 차이를 본다.
- grasp 성공 여부를 붙여서 **"핸드오프 상태에 따른 파지 성공률"**을 본다. 어디서 넘겨야 하는지를 데이터로 근거를 댄다.
- **Ablation:** HIL-SERL을 고정 리셋으로 학습한 경우와 VLA 분포 리셋으로 학습한 경우를 비교한다.

## 흐름 요약
1. 고정 환경 + 격자 위치 + 조명 변화에서 감으로 시연하고, 전체 궤적 FK를 로깅한다.
2. 궤적을 꽃 기준 상대 좌표로 바꾼다.
3. 자르는 규칙(X cm)으로 핸드오프 지점을 뽑고, 분포를 보고 클러스터링해서 H를 정한다.
4. 핸드오프 앞부분은 SmolVLA 학습, 뒷부분은 HIL-SERL demo buffer로 보낸다.
5. 튜닝한 VLA의 종료 분포를 같은 방식으로 측정해서 3번의 H와 비교한다.

## 구현 메모 (지금 코드와 다른 점, Claude 정리)
| 필요한 것 | 지금 상태 | 해야 할 것 |
|---|---|---|
| 시연에 **그리퍼 닫기** 포함 | `record_dataset.py`는 시연 중 그리퍼를 고정함 (reach 전용) | 시연 중 그리퍼도 기록되게 수정 (손으로 닫기 또는 키로 닫기) |
| 에피소드마다 **어느 격자 칸**인지 | 기록 안 함 (task 문장만) | 녹화할 때 칸 번호를 따로 저장 (task 문장에 넣으면 VLA 입력이 바뀌므로 별도 파일) |
| 격자 칸별 **p_f 실측** | 없음 | 그리퍼 끝을 꽃병 입구 중심에 대고 FK로 측정해서 저장 |
| 전체 궤적 FK | 데이터셋에 관절값이 있으므로 **나중에 계산 가능** (따로 로깅 불필요) | 분석 스크립트에서 계산 |
| 뒷부분을 HIL-SERL demo로 | SmolVLA 데이터는 관절 절대값 30fps, HIL-SERL은 EE 델타 `[dx,dy,dz,gripper]` 10fps | FK로 EE 델타를 만들고 10fps로 다시 샘플링해서 변환 (스텝 0.01m 넘는 이동은 잘림 주의) |
| 손목 카메라 화면 | 패드 교체 예정 | 패드를 단 뒤 trial2 수집 시작 |
